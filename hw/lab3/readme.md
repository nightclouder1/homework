# Лабораторная работа 3. Расчет подсетей IPv4 
### Задачи:
#### Часть 1. Определение подсетей по IPv4-адресу
### Решение:
#### Проблема 1:
                                          
|Дано:                    |                         |  
|-------------------------|-------------------------|
| IP-адрес узла:          |  192.168.200.139        | 
| Исходная маска подсети: |  255.255.255.0          |
| Новая маска подсети:    |  255.255.255.224        |

|Найти:                                        |                         |  
|----------------------------------------------|-------------------------|  
| Количество бит подсети                       | 3                       |  
| Количество созданных подсетей                | 8                       |  
| Количество бит узлов в подсети               | 5                       |  
| Количество узлов в подсети                   | 30                      |  
| Сетевой адрес этой подсети                   | 192.168.200.128         |  
| IPv4-адрес первого узла в этой подсети       | 192.168.200.129         |  
| IPv4-адрес последнего узла в этой подсети    | 192.168.200.158         |  
| Широковещательный IPv4-адрес в этой подсети  | 192.168.200.159         |  

#### Количество бит подсети:
255.255.255.0   - 11111111.11111111.11111111.00000000  
255.255.255.224 - 11111111.11111111.11111111. 111 00000
Количество бит подсети 111 - 3
/27 - /24 = 3
#### Количество созданных подсетей:
количество бит подсети n = 3 
кол-во созданных подсетей = 2^n = 2^3 = 8
#### Количество бит узлов в подсети:
255.255.255.224 - 11111111.11111111.11111111.111 00000
Количество бит узлов в подсети 00000 - 5
#### Количество узлов в подсети
Количество бит узлов в подсети h = 5  
2^h-2 = 2^5-2 = 32-2 (localhost , broadcast)
#### Сетевой адрес этой подсети
IP-адрес узла: 192.168.200.139       / 11000000.10101000.11001000.10001011  
Новая маска подсети: 255.255.255.224 / 11111111.11111111.11111111.11100000  

Умножаем каждый бит IP-адреса на соотетсвующий бит маски
|                         |                         |                         |
|-------------------------|-------------------------|-------------------------|
| 11000000                |  11111111               | 11000000                |
| 10101000                |  11111111               | 10101000                |
| 11001000                |  11111111               | 11001000                |
| 10001011                |  11100000               | 10000000                |

Сетевой адрес этой подсети = 11000000.10101000.11001000.100000000 = 192.168.200.128 

#### IPv4-адрес первого узла в этой подсети
Сетевой адрес подсети + 1 = 192.168.200.128 + 1    
Сетевой адрес подсети = 192.168.200.129   

#### IPv4-адрес последнего узла в этой подсети  
Последний узел = Сетевой адрес подсети(192.168.200.128) + Количество узлов (30) = 129 + 30 = 158  
IPv4-адрес последнего узла в этой подсети = 192.168.200.158  

#### Широковещательный IPv4-адрес в этой подсети  
Широковещательный IPv4-адрес в этой подсети = Последний узел (192.168.200.158) + 1 = 192.168.200.159  

#### Проблема 2:

|Дано:                    |                         |

| Исходная маска подсети: |  255.0.0.0              |

|Найти:                                        |                         |

| IPv4-адрес первого узла в этой подсети       | 10.101.0.1              |  
| IPv4-адрес последнего узла в этой подсети    | 10.101.127.254          |  
| Широковещательный IPv4-адрес в этой подсети  | 10.101.127.255          |  

#### Количество бит подсети:  
255.0.0.0 - 11111111.00000000.00000000.00000000    
255.255.128.0 - 11111111.11111111.10000000.00000000  
Количество бит подсети - 9  
/17 - /8 = 9
#### Количество созданных подсетей:  
количество бит подсети n = 9   
кол-во созданных подсетей = 2^n = 2^9 = 512    
#### Количество бит узлов в подсети:    
255.255.128.0 - 11111111.11111111.1 0000000.00000000    
Количество бит узлов в подсети 0000000.00000000 - 15  
#### Количество узлов в подсети  
Количество бит узлов в подсети h = 15    
2^15-2 = 2^15-2 = 32768-2 = 32766 (localhost , broadcast)  
#### Сетевой адрес этой подсети  
IP-адрес узла: 10.101.99.228 - 00001010.01100101.01100011.11100100            
Новая маска подсети: 255.255.128.0 - 11111111.11111111.10000000.00000000   

Умножаем каждый бит IP-адреса на соотетсвующий бит маски
|                         |                         |                         |
|-------------------------|-------------------------|-------------------------|
| 00001010                |  11111111               | 00001010                |
| 01100101                |  11111111               | 01100101                |
| 01100011                |  10000000               | 00000000                |
| 11100100                |  00000000               | 00000000                |

Сетевой адрес этой подсети = 00001010.01100101.00000000.00000000 = 10.101.0.0  
#### IPv4-адрес первого узла в этой подсети 
Сетевой адрес подсети + 1 = 10.101.0.0 + 1       
Сетевой адрес подсети = 10.101.0.1   

#### IPv4-адрес последнего узла в этой подсети  
Последний узел = Сетевой адрес подсети (10.101.0.0) + Количество узлов (32766) = 0 + 32766 = 32766
IPv4-адрес последнего узла в этой подсети = 10.101.127.254

#### Широковещательный IPv4-адрес в этой подсети  
Широковещательный IPv4-адрес в этой подсети = Последний узел (10.101.127.254) + 1 = 10.101.127.255
